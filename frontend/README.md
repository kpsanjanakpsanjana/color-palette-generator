# 🎨 Color Palette Generator

A web app that extracts color palettes from images.

Upload an image → Get colors → Download palette 🎨

## 🚀 Features

- Upload image
- Extract dominant colors
- Copy color codes
- Download palette as image

## 🛠 Tech Stack

- React (Vite)
- Node.js / Express
- html2canvas

## ⚙️ Installation

1. Clone the repo
git clone https://github.com/kpsanjanakpsanjana/color-palette-generator

2. Install dependencies
npm install

3. Run frontend
npm run dev

4. Run backend
node server.js
